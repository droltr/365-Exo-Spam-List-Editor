# Changelog

All notable changes to this project will be documented in this file.

## [1.0.0] - 2024-12-24

### Added
- Initial release of Exchange Online Spam Manager.
- Modern Windows Forms GUI with dark theme.
- Support for EOP Blocked Senders and Domains.
- Support for Transport Rules (Keywords, Emails, Domains).
- Bulk import from text file with auto-classification.
- Export functionality for backup.
- "Create Example" file generator.
- Standalone executable (`SpamManager.exe`).
- Detailed progress logging with timestamps.
- Connection status indicator and account display.

### Fixed
- Resolved layout issues with high-DPI displays.
- Fixed login button positioning and visibility.
- Corrected Transport Rules URL link.
- Improved error handling for connection failures.
